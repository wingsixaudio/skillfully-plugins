# Plugins written for Skillfully

A plugin written for Skillfully's own contract lives here as code: one folder per plugin, named after its id,
with a `plugin.json` at its top. See [CONTRIBUTING.md](../CONTRIBUTING.md).

There are none yet. The ones the hub ships with (the simulated devices, One fader, Controls) live in the
[platform repository](https://github.com/wingsixaudio/skillfully/tree/main/plugins) because its own tests need
them.
