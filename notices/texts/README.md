# License texts supplied by hand

When a bundled library ships no license text, the store credits it by name and adds the standard text of the
license it declares (see `../README.md`). If someone has that library's real license text, with its real
copyright line, it can be put here and is used instead.

Name the file after the library, with any `/` written as `__`, and end it `.txt`: `tr46.txt`,
`@scope__name.txt`. Say in the pull request where the text came from.
