# What the store tried to add and could not

Each file here is one module the catalog fill looked at and left out, with the reason. They are kept so the
same module is not built again every time the fill runs.

A module is looked at again when its author releases a newer version. One that was left out because of
something on this side (the hub cannot run its kind yet, or it would not build or start) is also looked at
again whenever the hub the store checks against, the store's way of building, or the list of libraries under
`notices/` changes.

Nobody edits these by hand. To have one tried again now, delete its file.
